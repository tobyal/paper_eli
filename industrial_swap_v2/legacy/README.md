# Historical implementations

`pre_four_module_cleanup/` contains byte-preserved source snapshots and a SHA256
manifest. These files are archival source, not importable pipeline entry points;
their relative imports and original experiment paths intentionally remain intact.
Nothing in the official pipeline imports this directory.

For a runnable historical comparison, create a separate checkout of source commit
`071e179d1d63fed4605d1108f17cadfe293b5647` and select a NEW experiment output directory.
That commit includes the original source layout, configuration, and dependencies.
Do not run archived launchers against existing results.

Archived methods: DI-SDS/object appearance training; bbox-based RGB exclusion and
coupled background permissions; height diagnostics; ground fitting/patches;
direct deletion/OAGOF; their runners, audits, tests and historical documentation.
Original experiments, caches, PLY, checkpoints and records remain in place.
See `pre_four_module_cleanup/README.md` for the original experiment descriptions.
