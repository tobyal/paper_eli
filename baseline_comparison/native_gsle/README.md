# GSLE independent paper-derived complete-flow baseline

This is a reproduction of WACV 2025 GSLE, not an author-released implementation. The existing generation kernels are copied into `vendor/gsle_native`; `gsle/` and earlier controlled-localization experiments remain untouched.

Inputs: original Gaussian scene, original complete COLMAP calibration, trained LangSplat fields/autoencoder, and exact A/B text. `query_language.py` has no reference photo, SAM ID or image prototype. It computes official LangSplat text-vs-generic-negative relevance over all three 3D fields. `localize.py` chooses voxel-connected semantic components using normalized positive text evidence. This component selection, automatic review-camera selection and semantic floor/up estimation are explicit industrial adaptations, not published GSLE details. Their candidates, scores and thresholds are recorded. Generation space equals this independently derived localization box; no upright height enlargement is applied.

AVP uses 100 azimuths and eight in-plane rotations. The actual selector is fixed in advance to the literal supplement Algorithm 1, `argmin(abs(min(S-1)))`. The main-paper contrast objective disagrees mathematically; both scores and choices are saved, and the contrast alternative is not used to select a better result. A predeclared sequence of radius/elevation adjustments is permitted only when every view fails geometry-based visibility/coverage constraints.

Subsequent stages reuse depth-conditioned SD Inpainting, ControlNet, generic box/text-ranked SAM, spherical Gaussian initialization, Stable Zero123/3D-SDS and context-aware DI-SDS. No Qwen, TRELLIS or Ours asset is read. Existing fixed-seed inpainting candidate ranking is disclosed. Coarse runs 6500 steps (supplement section 1.3; 1.2 also says 3500), refinement 2000; effective random-view batches remain 6 and 4. Gradient microbatching changes memory usage, not the effective batch or loss weights. The original background and pretrained models remain frozen. The ambiguous DI-SDS unconditional branch uses the existing `drop_all_eq7` interpretation, recorded in configuration.

Run: `python3 baseline_comparison/native_gsle/run.py case00 --gpu 3`. Optional `--through foreground` prepares actual inputs before training. Every stage is isolated, logged and resumable at stage boundaries; failed attempts require explicit preservation before recovery. `export.py` uses real step 0/3500/6500 and coarse-final/refine-1000/refine-2000 images, plus final PLY renders in three original cameras.

References: https://openaccess.thecvf.com/content/WACV2025/papers/Xiao_Localized_Gaussian_Splatting_Editing_with_Contextual_Awareness_WACV_2025_paper.pdf and https://openaccess.thecvf.com/content/WACV2025/supplemental/Xiao_Localized_Gaussian_Splatting_WACV_2025_supplemental.pdf
